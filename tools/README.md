# Utilities and Tools

This folder contains scripts and tools for helping out with stuff like pipeline setup and testing.

Here's a little table of the tool and what they do

| Script                                 | Description                                                                                                |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [setup_test_env.py](setup_test_env.py) | Sets up the test environment by fetching any required dependencies, used in pipeline before `run_tests.py` |
| [run_tests.py](run_tests.py)           | Sets up the module path and runs my tests, used in pipeline                                                |
